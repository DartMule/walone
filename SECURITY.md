# Безопасность

При обнаружении уязвимости сообщите владельцу проекта приватно.
Если для репозитория включена функция GitHub «Report a vulnerability»,
используйте её. Не прикладывайте действующие ключи, cookies, личные
медиатеки или записи глобального ввода к публичным issues и PR.

Опишите затронутую версию, платформу, шаги воспроизведения и возможное влияние.
Исправления безопасности выпускаются для последней распространяемой версии.
Гарантированного срока ответа пока нет.

## Подпись и обновления

macOS-релизы должны быть подписаны Developer ID Application и пройти
нотариализацию Apple. Sparkle проверяет подпись Ed25519 до распаковки обновления.
Публичный ключ в `Info.plist` не является секретом. Закрытый ключ Sparkle,
сертификаты с закрытыми ключами и учётные данные Apple остаются в Keychain.

Gitleaks проверяет публикуемые файлы в CI. Исключения в `.gitleaks.toml`
ограничены известными SHA-256 хешами и конкретным именем настройки.
Сканирование не доказывает отсутствие всех возможных секретов.

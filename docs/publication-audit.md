# Проверка перед публикацией — 20 октября 2026

Проверен локальный проект Walone, подготовленный для `DartMule/walone`.
На момент первичного аудита исходники и релизы на GitHub не публиковались.

## Структура и документация

- Содержимое `flutter_app/` перенесено в корень; исходники, ресурсы и локальные
  кэши сохранены. Настройки VS Code и конфигурация Flutter обновлены под новый путь.
- README описывает установку, возможности, платформы, разработку и документы.
  Исторические замеры отделены в `docs/development-notes.md` и отмечены как архив.
- Добавлены CONTRIBUTING, SECURITY, CHANGELOG, описание данных и руководство
  по релизам. Проверены относительные ссылки между основными Markdown-документами.
- Удалена ссылка на личный абсолютный путь в документации. Исправлено утверждение
  о наличии аудиоотчёта в репозитории: теперь указана команда его генерации.
  Ресурсная копия документа пересоздана генератором; обновлён только его SHA-256.
- Для оригинального кода подготовлена неизменённая PolyForm Noncommercial 1.0.0.
  Коммерческое использование требует отдельного разрешения. Сторонние записи и
  зависимости сохраняют свои лицензии; их тексты и источники сохранены.

## Секреты и состав публикации

Gitleaks **8.30.1** проверил снимок всех файлов, которые Git разрешает добавить
с учётом `.gitignore`, с редактированием значений в выводе (`--redact`).
После разбора ложных срабатываний секреты не обнаружены.

Первоначальные 114 находок:

- 112 хешей SHA-256 в `tool/resource_sources/bundled-sha256.json`.
- Два упоминания публичного имени настройки `intensityCalibration.v1`.

Исключения ограничены конкретными путями, правилом `generic-api-key` и форматом
значения. Дополнительная проверка с искусственным API-ключом в исключаемом
манифесте подтвердила, что другие секреты продолжают обнаруживаться.

В публикацию не входят сборки, профили Instruments, кэши Flutter/FVM,
пользовательские настройки IDE, `.env`, сертификаты и закрытые ключи.
Файлов с секретными расширениями и пользовательских сессий в снимке не найдено.
Публичный ключ Sparkle в Info.plist можно распространять; закрытый ключ хранится
в macOS Keychain под account `dev.soyjanks.walone.flutter`.

Изначально Git-репозитория в каталоге не было, поэтому старой истории для
проверки нет. После первичного аудита владелец явно разрешил первый коммит
и публичную публикацию. CI настроен на проверку текущих файлов и Git-истории.
Сканер не доказывает отсутствие всех возможных видов секретов и персональных данных.

# Данные и конфиденциальность

Walone сохраняет настройки, историю, статистику, калибровку и медиатеку
локально. Данные приложения находятся вне `.app`, поэтому замена приложения
при обновлении не должна удалять их. Форматы и расположение хранилищ описаны
в разделе «Данные» [технических заметок](development-notes.md).

Разрешение «Мониторинг ввода» используется для озвучивания клавиш вне окна
Walone. Пробный текст не сохраняется в хранилище. Исходники нативных мостов —
в `macos/Runner/` и `windows/runner/`. Экспериментальный датчик включается
отдельно; его условия описаны в [sensor.md](sensor.md).

Встроенным звукам и локальной музыке сеть не нужна. При импорте приложение
обращается к выбранной службе, а при установке инструментов — к их источникам.
Вход VK использует отдельное WebView; сессионные данные сохраняются локально.
Не прикладывайте папку данных WebView к отчётам об ошибках.

В распространяемых macOS-сборках Sparkle обращается к GitHub за описанием
обновлений и выбранной новой версией. GitHub получает обычные сетевые сведения
запроса, включая IP-адрес. Системное профилирование Sparkle по умолчанию
выключено; настройки, музыка и история ввода в запрос обновления не включаются.

Автообновление необходимо отдельно испытать между двумя подписанными
версиями, включая сохранность медиатеки, незавершённых операций и системных
разрешений. До такой проверки механизм не прошёл полную приёмку.

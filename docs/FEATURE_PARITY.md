# Соответствие функций Walone

Проверка исходников Swift и Flutter от 18 октября 2026. Основное приложение —
корень репозитория. Старое нативное приложение и его архив удалены после проверки переноса.

## Функции

| Область | Соответствие во Flutter | Проверка |
| --- | --- | --- |
| Клавиатура | Все 20 наборов, поиск, выбор, история, предварительное прослушивание и 4 группы клавиш | keyboard_test, keyboard_catalog_test, keyboard_native_test |
| Пробная печать | Восстановлено текстовое поле; текст не пишется в хранилище | keyboard_test |

| Атмосфера | 10 источников, 14 WAV, циклы и редкие голоса, отдельные уровни | check_migration.py, media_test, tool/audio/check-atmosphere-clips.py |

| Настройки и трей | Автозапуск, скрытие/возврат, меню наборов, выход с сохранением | settings_test; изменения в этой работе не меняют регистрацию ОС |

| Датчик | Перенесены включение, чувствительность, индикатор, серии, сбор/сброс, калибровка и экспорт schema 5 | sensor_test, tool/sensor_check.swift, настоящий канал в keyboard_native_test |
| Перенос данных | Завершён; кнопки и код переноса удалены по запросу пользователя. Текущие данные и формат хранилищ сохранены | Проверки текущих медиатеки, истории, атмосферы и калибровки |

У датчика сохранены прежние SensorStream, ImpactEstimator и IntensityCalibration.
Сигнал приходит через stdin на нативном фоновом потоке; каждое нажатие обрабатывается
нативно. В Dart передаётся только снимок состояния. Наблюдения и причины пропусков,
процентили амплитуд, временные метрики, якоря и флаги сохраняются в том же schema 5.
Без потока работает прежний запасной режим. На Windows датчик недоступен, как
и в исходном приложении для macOS.

## Свежая автоматическая проверка

Все команды Flutter/Dart выполнены последовательно через resource_queue.

- Исходный набор: 33 теста прошли.
- Новые проверки выявили отсутствие поля печати, CC-лицензий и тёмной темы;
  до исправления они завершались ошибкой.
- Итоговый `flutter test --no-pub --concurrency=1`: **35 тестов прошли**,
  включая системную тёмную тему, пробную печать, лицензии и управление датчиком.
- Итоговый `flutter analyze --no-pub`: **замечаний нет**.
- `flutter build macos --debug --no-pub`: приложение собрано с новым мостом
  датчика и обновлёнными ссылками на общие Swift-файлы.
- `keyboard_native_test.dart -d macos`: 1 тест прошёл на настоящем Runner;
  все наборы загружены, звук проверен при нулевой громкости, датчик отвечает
  через MethodChannel и отклоняет неверную чувствительность без изменения состояния.
  При запуске теста система сообщила `Failed to foreground app; open returned 1`,
  при этом тест подключился и завершился успешно.
- `tool/sensor_check.swift`: искусственный сигнал проходит через настоящий
  SensorStream и SensorExperiment, меняет уровень звука и попадает в сводку.
  Проверены schema 5, валидная/ошибочная калибровка, её сохранение/восстановление,
  сброс и обычный режим без датчика. Аппаратные привилегии не используются.
- `python3 tool/check_migration.py`: 172 клавиатурных и 14 фоновых WAV и
  лицензии и VK-скрипты совпадают с эталоном SHA-256 до переноса;
  Swift-файлы Xcode находятся внутри macos/Runner. Проверка не читает архив.

## Ограничения приёмки

Сопоставление исходников и автоматические проверки не подтверждают реальное
поведение каждой внешней службы и аппаратуры. В этой работе не выполнялись:

- Сборка/запуск Windows, реальный повторный вход в ОС и перезапуск Explorer.
- Новая авторизация и живые загрузки VK/YouTube/SoundCloud.
- Реальные серии датчика с sensor-probe/sudo, субъективная задержка звука,
  отключение Bluetooth/USB-наушников и длительный сеанс печати.
- Повтор медиа-, трей- и AX-native-тестов; их исходники сохранены.
- Изменение автозапуска или данных пользовательской медиатеки.

## Завершение переноса

Все рабочие зависимости находятся внутри корень репозитория:

- `macos/Runner/` — KeyboardAudio, AudioOutputMonitor, SensorStream,
  ImpactEstimator и IntensityCalibration рядом с платформенными мостами.
  Ненужный Swift-плеер атмосферы не компилируется; загрузка ресурсов из
  WaloneExperiment.bundle удалена.
- `tool/resource_sources/` — источники WAV, исходные записи, параметры нарезки,
  лицензии и самостоятельные JS-исходники VK. Генератор не извлекает JavaScript
  из классов старого приложения.
- `tool/audio/` — подготовка и проверка звуков; `tool/sensor-probe.c` — утилита
  датчика; `docs/sensor.md` — актуальные условия её аппаратного запуска.
- `assets/` — сгенерированные ресурсы для обеих платформ. Все SHA-256 аудио и VK-скриптов
  совпадают с состоянием до переноса. В SOURCES.md обновлены пути к инструментам.

Архив старого нативного приложения удалён вместе с его Swift Package, тестами,
отчётами, собранной WaloneExperiment.app и кэшем сборки. Все необходимые
функции, источники записей и лицензии перенесены в самостоятельный Flutter-проект.
Явный перенос пользовательских данных из UserDefaults и выбранной медиатеки
на этом этапе был сохранён; после завершения переноса он удалён по запросу пользователя.

При финальной проверке папка `legacy/` была временно недоступна по прежнему
пути. В этом состоянии успешно выполнены:

- Генерация ресурсов и автономная проверка SHA-256 всех assets.
- Проверки 172 клавиатурных и 14 фоновых WAV: 0 ошибок.
- Сборка sensor-probe с `-Wall -Wextra -Werror` без запуска устройства.
- Проверка SensorExperiment искусственным сигналом из локальных Swift-файлов.
- `flutter analyze --no-pub`: замечаний нет.
- `flutter test --no-pub --concurrency=1`: 35 тестов прошли.
- `keyboard_native_test.dart -d macos`: 1 тест прошёл на настоящем Runner.
- `flutter build macos --release --no-pub`: Release собран.

Установка выявила ошибку обработки LaunchServices `-10814` для копии,
исключённой из Spotlight. Исправление принимает только известные коды
отсутствующей регистрации; остальные ошибки сохраняются. Два Python-теста
установщика прошли, в том числе новый тест этого случая. Заключительная
установка повторена без пересборки приложения и без доступа к `legacy/`.
После успешной проверки и установки архив удалён по запросу пользователя.

При переносе также исправлены существовавшие до него неверный аргумент
`Utf8Decoder(_allowMalformed: ...)` и проверка каталога клавиатур, ошибочно
включавшая WAV атмосферы. Аудиоданные, идентификатор приложения, формат
хранилищ и designated requirement установленной версии сохранены.

## Проверка после удаления старого приложения

Архив `legacy/`, старый кэш `local.walone.experiment`, неиспользуемые копии
скриптов подготовки и временная резервная копия исходного нативного проекта
перемещены в Корзину. Подготовка ресурсов не создаёт эти копии заново.
В SOURCES.md указаны рабочие инструменты из `tool/audio/`; обновлён только
соответствующий текстовый хеш эталона, аудиоданные не менялись.

После удаления генерация и автономная проверка ресурсов прошли;
`flutter test test/keyboard_test.dart --no-pub --concurrency=1`: 5 тестов прошли.
Подпись установленной Walone проверена, Spotlight находит одну копию.
Полная повторная сборка не выполнялась: изменены документация и инструменты
подготовки, исполняемый код приложения не менялся. Пользовательские данные
сохранены. После подтверждения пользователем завершения переноса кнопки,
обработчики Dart и Swift, чтение старых UserDefaults и объединение старой
медиатеки удалены. Загрузка калибровки из сводки и обычный импорт музыки сохранены.

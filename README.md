# Walone

Звуки клавиатур, фоновая атмосфера и локальная музыка для сосредоточенной работы.
Приложение на Flutter с нативными аудиодвижками и интеграцией с рабочим столом.

## Возможности

- 20 наборов звуков клавиатур с предварительным прослушиванием.
- Дождь, океан, поезд, кафе, ветер, птицы и шумы с отдельными уровнями.
- Медиатека на SQLite: исполнители, плейлисты, поиск и групповые действия.
- Автоматический перенос из JSON с резервной копией; совместимые ZIP-архивы.
- Несколько исполнителей у трека, редактирование названия, нарезка и восстановление позиции.
- Импорт видео и плейлистов YouTube, SoundCloud и VK с настраиваемым лимитом.
- Импорт метаданных Spotify через spotDL с поиском подходящих записей на YouTube.
- Таймеры работы и отдыха, статистика активности и сохранённые наборы.
- Светлая, тёмная и системная темы; управление из строки меню или трея.
- Обновления через GitHub Releases: Sparkle на macOS, подписанный установщик на Windows.

## Платформы и установка

Основная платформа — **macOS 14+**, Apple Silicon и Intel. Реализация Windows
10/11 присутствует, но перед первым Windows-релизом нужна отдельная приёмка.

Подписанный установщик доступен в
[последнем GitHub Release](https://github.com/DartMule/walone/releases/latest).
Выберите файл `.dmg` в разделе Assets.
Для установки откройте DMG и перетащите Walone в «Программы».

Для Windows в релизе 0.1.4 доступен QA-установщик `*-windows-x64-qa-setup.exe`.
Он устанавливается для текущего пользователя и пока не подписан Windows-сертификатом;
автообновления этой QA-копии отключены.

Для глобальных звуков клавиатуры macOS запрашивает «Мониторинг ввода».
Закрытие окна оставляет приложение в строке меню;
для полного выхода выберите «Завершить Walone».

Проверка обновлений доступна в настройках и меню. Новые версии проверяются
при каждом запуске и загружаются в фоне. При обнаружении версии рядом с
настройками появляется круглая кнопка со стрелкой вверх. Готовую версию можно
установить кнопкой
«Обновить и перезапустить»; при обычном выходе она установится автоматически.
Отладочные сборки
из исходников не обновляются через Sparkle.

## Разработка

Нужны Flutter **3.47.4** (версия закреплена в `.fvmrc`), Python 3,
а для macOS — Xcode с установленными command line tools.
FVM должен быть установлен; команды выполняются из корня репозитория.

```sh
fvm install
fvm flutter pub get
python3 tool/prepare_assets.py
python3 tool/check_migration.py
fvm flutter run -d macos
```

На Windows используйте `-d windows`; нужны Visual Studio с C++ и Windows SDK,
для входа VK — WebView2 Runtime. Встроенные звуки работают без сети.
FFmpeg нужен только для повторной обработки исходных аудиозаписей;
обычная подготовка готовых ресурсов не требует его установки.

На рабочем Mac сборки, тесты и анализ запускаются последовательно через
общую очередь. После `fvm install`, например:

```sh
python3 tool/resource_queue.py .fvm/flutter_sdk/bin/flutter analyze --no-pub
python3 tool/resource_queue.py .fvm/flutter_sdk/bin/flutter test --no-pub --concurrency=1
python3 -m unittest discover -s tool -p '*_test.py'
```

Зависимости закреплены в `pubspec.lock` и Swift `Package.resolved`.
CI проверяет ресурсы, Python-тесты, анализ, Flutter-тесты и Release-сборки
macOS/Windows; Windows-задача также сохраняет QA-установщик.
Подпись и публикация выполняются отдельно на соответствующей платформе.

## Структура

| Путь | Содержимое |
| --- | --- |
| `lib/` | Flutter-интерфейс, состояние и работа с данными |
| `macos/`, `windows/` | Нативные мосты, аудио и интеграция с ОС |
| `assets/` | Ресурсы приложения |
| `tool/` | Подготовка ресурсов, проверки, измерения и выпуск релизов |
| `tool/resource_sources/` | Исходные записи, манифесты, лицензии и JS-исходники |
| `test/`, `integration_test/` | Модульные, виджетные и нативные тесты |
| `docs/` | Дизайн, ограничения, релизы и технические заметки |

# Изменения

## 0.1.2 — 20 октября 2026

- Новая иконка Walone: персиковая W-волна на сливовом фоне.

## 0.1.1 — 20 октября 2026

- Добавлена неброская кнопка обновления рядом с «Настройками»; видна, когда доступна новая версия.
- Проверен полный цикл обновления с 0.1.0 через Sparkle с сохранением данных.
- Формат пользовательских настроек, медиатеки и статистики сохранён.

## 0.1.0 — 20 октября 2026

- Первый выпуск macOS через GitHub Releases: DMG, подпись Developer ID,
  нотариализация Apple и подписанное описание обновлений Sparkle.
- Добавлена проверка обновлений в настройках и строке меню.
- Flutter-проект перенесён в корень репозитория.
- Добавлены правила участия, описание данных, лицензия некоммерческого
  использования оригинального кода и автоматические проверки.

- Исправлено завершение очереди ресурсов на GitHub Actions после успешной команды.
